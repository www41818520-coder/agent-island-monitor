Windows Codex 小岛监控器 - 功能说明

项目位置：
E:\08-codex project\agent-island-monitor

一、这个工具是做什么的

这是一个 Windows 顶部悬浮的 AI 状态迷你胶囊。平时只显示极小状态点，尽量不遮挡网页顶部按钮和文字；当 Codex 有运行、完成或需要你处理的事件时，才舒展开显示极简状态胶囊。手动展开后如果 2 秒无人操作，会自动回到迷你胶囊。需要处理或任务刚完成时，即使小岛已经收回迷你态，外圈也会出现同色 LED 流光提醒。

当前监控：

1. Codex
   - 读取本机 Codex 的本地状态文件和日志。
   - 判断 Codex 大致处于 Running、Needs You、Done、Idle、Offline 哪种状态。
   - 展开后只显示 Codex 状态胶囊，不显示日志或线程列表。

2. Cursor/CC
   - 检测 Cursor 是否运行。
   - 检测 Cursor 窗口是否处于前台。
   - Cursor 开着但不在前台时显示 Open，不再显示 Running。
   - 当前不会精确判断 DeepSeek/Claude 是否正在生成，只做窗口和进程级轻量监控。

3. 自动发现的 Agent
   - 自动识别本机常见 AI 工具窗口或进程，例如 Claude、Copilot、Windsurf、Trae、Cline 等。
   - 只显示 Active / Open，不显示 Running。
   - Active 表示该 Agent 窗口在前台。
   - Open 表示检测到该 Agent，但它不在前台。
   - 自动发现只代表“这个工具开着”，不代表它正在思考、生成或写代码。

二、状态含义

Codex:

- Running：检测到真实 Codex runner 或明确活跃任务。
- Needs You：检测到授权、确认、等待输入、需要处理等线索。
- Done：最近有 Codex 线程记录，但当前没有明显运行活动。
- Idle：Codex 程序存在，但最近没有明显任务活动。
- Offline：没有检测到 Codex 相关活动。

Cursor/CC:

- Active：Cursor 是当前前台窗口。
- Open：Cursor 开着但不在前台；这不代表 DeepSeek/Claude 正在生成。
- Offline：没有检测到 Cursor 进程。

自动发现的 Agent:

- Active：该 Agent 窗口是当前前台窗口。
- Open：检测到该 Agent 的窗口或进程，但它不在前台。
- 自动发现不会读取模型内部状态，因此不会判断 DeepSeek、Claude 或其他模型是否正在生成。

三、默认迷你胶囊逻辑

- Idle / Open / Offline：保持迷你胶囊。
- Running：状态变化时展开约 4 秒，然后自动回到迷你胶囊。
- Done：完成时展开约 4 秒，然后自动回到迷你胶囊。
- Needs You：先展开提醒，然后自动回到迷你胶囊，并用对应颜色的流动灯带持续提示。
- Done 回到迷你胶囊后：外圈短时间显示完成流光。

四、交互方式

点击迷你胶囊：
- 展开状态胶囊，2 秒无人操作后自动收回。
- 连续极快点击会被轻量防抖，避免大小胶囊动画反复打断造成卡顿。

按住拖动小岛：
- 可以把小岛移动到屏幕其他位置。
- 松开后会自动保存位置。

右键小岛：
- 恢复默认位置。
- 关闭。
- 如果右键的是自动发现的 Agent 胶囊，还可以标记为确认的 Agent，或忽略它。

展开态点击 Codex 胶囊：
- 单击只切换大小胶囊；双击才尝试召唤 Codex 窗口到前台，并最大化显示。

展开态点击 Cursor/CC 胶囊：
- 单击只切换大小胶囊；双击才尝试召唤 Cursor 窗口到前台，并最大化显示。

展开态点击自动发现的 Agent 胶囊：
- 单击只切换大小胶囊；双击才尝试召唤对应窗口到前台，并最大化显示。

双击迷你胶囊：
- 默认召唤 Codex 窗口到前台，并最大化显示。

展开态点击空白区域：
- 收回迷你胶囊。

按 Esc：
- 关闭小岛。

五、托盘菜单

右键系统托盘里的 Agent Island 图标，可以使用：

- 显示/隐藏小岛
- 安静模式
- 静音提醒
- 开机自启
- 退出

六、配置文件

配置文件：
config.json

可以调整：
- 刷新间隔
- 迷你胶囊尺寸
- 自定义位置
- 手动展开自动收回时间
- 大小胶囊过渡速度
- 动画开关
- 鼠标靠近自动上收备用功能
- 静音提醒
- 小岛颜色
- Codex 活跃和 Needs You 判断时间阈值
- 自动发现 Agent 开关
- 最大显示 Agent 数量
- 已确认 / 已忽略 Agent 列表

七、当前限制

1. Gemini 网页端暂未监控。

2. Cursor/CC 目前只做轻量检测。
   它不能直接知道 CC 转接的 DeepSeek 是否已经生成完成。

3. 自动发现的 Agent 也只做轻量检测。
   它只能知道程序或窗口是否存在，不能知道模型内部是否正在生成。

4. Codex 状态基于本地 sqlite/log 进行推断。
   如果 Codex 后续版本更改本地状态文件结构，可能需要更新监控逻辑。

5. Windows 有时会限制程序强制切换前台窗口。
   如果点击不能切过去，说明被系统前台窗口策略拦住，不是小岛崩溃。
