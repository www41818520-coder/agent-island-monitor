Windows Codex 小岛监控器 - 功能说明

项目位置：
E:\08-codex project\agent-island-monitor

一、这个工具是做什么的

这是一个 Windows 顶部悬浮小窗，外观接近苹果“灵动岛”，用于在你做其他事情时快速查看后台 AI 工具的大致状态，并作为一键最大化召唤工作窗口的入口。

当前监控两项：

1. Codex
   - 读取本机 Codex 的本地状态文件和日志。
   - 判断 Codex 大致处于 Running、Needs You、Done、Idle、Offline 哪种状态。
   - 展开后会显示最近多个 Codex 线程，并按 Needs You、Running、Done/Idle 的优先级排序。

2. Cursor/CC
   - 检测 Cursor 是否运行。
   - 检测 Cursor 窗口是否处于活跃状态。
   - 这里的 Cursor/CC 指你的 Cursor + CC/Claude Code 转接工作环境。
   - 当前不会精确判断 DeepSeek 生成是否完成，只做窗口和进程级轻量监控。

二、状态含义

Codex:

- Running：最近有 Codex 日志活动，并且 Codex/runner 进程存在。
- Needs You：最近日志中出现授权、确认、等待输入、失败、需要处理等线索。
- Done：最近有 Codex 线程记录，但当前没有明显运行活动。
- Idle：Codex 程序存在，但最近没有明显任务活动。
- Offline：没有检测到 Codex 相关活动。

Cursor/CC:

- Active：Cursor 正在运行，并且当前前台窗口是 Cursor。
- Running：Cursor 正在运行，但不是当前前台窗口。
- Idle：检测到 Cursor 进程，但没有可靠窗口标题。
- Offline：没有检测到 Cursor 进程。

三、交互方式

点击 Codex 胶囊：
- 尝试召唤 Codex 窗口到前台，并最大化显示。

点击 Cursor/CC 胶囊：
- 尝试召唤 Cursor 窗口到前台，并最大化显示。

点击小岛空白区域：
- 展开或收起详情。

按 Esc：
- 关闭小岛。

四、提醒和动画

- Running：状态点会有轻微呼吸动画。
- Needs You：状态点会变成琥珀色脉冲，并显示需要你处理的提示。
- Done：从 Running 或 Needs You 变成 Done/Idle 时，会播放提示音，并出现短暂绿色完成扫光。
- 每个状态会显示持续时间，例如 Running · 3m、Needs You · 18s。

五、系统托盘菜单

右键系统托盘里的 Agent Island 图标，可以使用：

- 显示/隐藏小岛
- 安静模式
- 静音提醒
- 开机自启
- 退出

左键托盘图标：
- 显示或隐藏小岛。

六、安静模式

安静模式开启后，小岛在普通状态下会收缩成极简黑色胶囊，只保留状态点。

以下情况会临时显示完整状态：
- 状态发生变化
- Codex 进入 Needs You
- Codex 刚刚完成
- 手动点击展开

七、启动和开机自启

手动启动：
双击 start_agent_island.bat

开机自启脚本：
install_startup.ps1

取消开机自启脚本：
uninstall_startup.ps1

启动项位置：
C:\Users\Administrator\AppData\Roaming\Microsoft\Windows\Start Menu\Programs\Startup\Agent Island.lnk

八、配置文件

配置文件：
config.json

可以调整：
- 刷新间隔
- 安静模式
- 静音提醒
- 动画开关
- 小岛尺寸
- 颜色
- Codex 活跃和 Needs You 判断时间阈值
- 展开态显示的 Codex 线程数量

九、当前限制

1. Gemini 网页端暂未监控。

2. Cursor/CC 目前只做轻量检测。
   它不能直接知道 CC 转接的 DeepSeek 是否已经生成完成。

3. Codex 状态基于本地 sqlite/log 进行推断。
   如果 Codex 后续版本更改本地状态文件结构，可能需要更新监控逻辑。

4. Windows 有时会限制程序强制切换前台窗口。
   如果点击不能切过去，说明被系统前台窗口策略拦住，不是小岛崩溃。
